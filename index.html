// Skema Arsitektur Layer
InputLayer (224, 224, 3)
↓ [Conv2D (64 filters, 3x3) + ReLU] x 2 → MaxPooling2D
↓ [Conv2D (128 filters, 3x3) + ReLU] x 2 → MaxPooling2D
↓ [Conv2D (256 filters, 3x3) + ReLU] x 3 → MaxPooling2D
↓ GlobalAveragePooling2D / Flatten
↓ Dense (256 units) + BatchNormalization + Dropout (0.4)
↓ Dense (64 units) + ReLU
↓ Output: Dense (1 unit, Linear activation)
Optimizer & Loss Adam (lr=1e-4), Loss: MSE
Target Metrics MAE: ~2.41 BMI Units
